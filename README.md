# GodsOfStrategy QA Portfolio

## Project Overview

GodsOfStrategy is an online competitive gaming platform focused on strategy-based games.

This repository contains QA documentation created for the platform, including user stories, test cases, bug reports, and test execution records.

## QA Scope

- Requirement analysis
- User story analysis
- Manual testing
- Test case design
- Bug reporting
- Test execution
- Jira Xray test management

## Tools

- Jira
- Xray Test Management
- GitHub
- Agile / Scrum methodology

## Project Modules

- User Authentication
- User Profile
- Chess Gameplay
- Tournaments
- Rating & Leaderboard
- Security & Anti-Cheat

Currently under development.

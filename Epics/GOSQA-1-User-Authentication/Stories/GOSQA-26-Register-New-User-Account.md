# GOSQA-26 – Register a New User Account

## Epic

**GOSQA-1 – User Authentication**

---

## Summary

Register a new user account.

---

## Description

The platform should allow new users to create an account using a username, email address, and password.

---

## Business Requirements

- Users can access the registration page.
- Users can enter the required account information.
- The system validates the registration data.
- Duplicate usernames or email addresses are not allowed.
- A new user account is created successfully after valid registration.

---

## Related Test Cases

- TC-001 – Verify successful user registration
- TC-002 – Verify registration fails when using an existing email address
- TC-003 – Verify registration fails when required fields are left empty
